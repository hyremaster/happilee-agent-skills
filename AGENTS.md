# Happilee Agent Skills

WhatsApp Business automation skills for AI agents. Works with Claude Code, Cursor, Copilot, VS Code, Windsurf, and 20+ agent platforms.

## Prerequisites

These skills work best with the [Happilee MCP Server](https://github.com/hyremaster/happilee-mcp-server) installed. The MCP server provides 43 tools for WhatsApp Business automation. Skills provide guided workflows that chain those tools together.

## Available Skills

| Skill | Trigger | Description |
|-------|---------|-------------|
| `happilee-broadcast` | "send broadcast", "campaign", "bulk message" | Guided broadcast campaign creation |
| `happilee-cart-recovery` | "abandoned cart", "recover orders", "RTO" | End-to-end abandoned cart recovery |
| `happilee-campaign-report` | "campaign report", "broadcast analytics" | Analytics report with insights |
| `happilee-daily-digest` | "daily digest", "morning report", "what happened today" | Morning dashboard summary |
| `happilee-contact-onboarding` | "new contact", "onboard customer" | Interactive contact onboarding flow |
| `happilee-whatsapp-best-practices` | "whatsapp tips", "avoid ban", "template approval" | WhatsApp marketing compliance rules |

## Installation

```bash
npx skills add hyremaster/happilee-agent-skills
```
